# 🎬 IMDb Movies Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing IMDb movie and director data using SQL to extract meaningful insights about movie popularity, ratings, revenue, and director performance.

## 🎯 Project Objectives

* Analyze movie and director information.
* Identify the most popular and highest-revenue movies.
* Analyze female directors.
* Identify directors with the highest number of movies.
* Evaluate directors based on total movie revenue.

## 🗂️ Database Structure

The project uses two tables:

**1. Movies**

* Movie ID
* Original Title
* Budget
* Popularity
* Release Date
* Revenue
* Vote Average
* Vote Count
* Director ID

**2. Directors**

* Director ID
* Name
* Gender
* Department
